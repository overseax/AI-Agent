# 动手做 AI Agent｜24 篇实战，从一次模型调用开始

> 不急着造一个“全自动智能体”。先让模型调用跑通，再一步步让程序学会理解输入、调用工具、处理结果，最后把 Agent 做成真正能用的东西。

大家好，我是**第二线程**。

这个仓库用来存放微信公众号「第二线程」**《动手做 AI Agent》24 篇系列**的配套代码、练习样例和运行说明。

我想把每一步都拆小一点：代码尽量能自己跑，关键配置交代清楚，遇到错误知道往哪儿查。文章负责讲为什么这么做，仓库负责让你动手验证。

**适合谁？** 会一点 Python、想从零动手做 Agent 的开发者，以及正在尝试将大模型接入现有项目的朋友。不要求一开始就懂复杂的 Agent 框架。

## 这个系列怎么学

每一篇围绕一个可验证的小目标展开。建议按编号顺序练习：

1. 先运行本地预览，确认输入内容和执行范围。
2. 看清楚代码要访问的服务、使用的模型及可能产生的费用，再开启真实调用。
3. 对照样例检查输出，别只看“有没有返回文字”。
4. 把遇到的错误记下来，下一次运行才知道改进了什么。

系列共计划 **24 篇**。具体篇目名称和目录以实际发布、上传的内容为准，不在这里提前写死。
